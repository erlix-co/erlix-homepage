תוסף Gmail בדפדפן כרום

בתוסף Gmail בדפדפן כרום אנחנו מזהים דפוסים מסוכנים לפני השליחה ומתריעים למשתמש לעצור ולתקן. בגלל מגבלות סביבת הדפדפן והאינטגרציה של Gmail, זו הגנה חשובה אך לא מוחלטת.

תוסף Outlook

בתוסף Outlook ההתרעה מחוברת עמוק יותר לזרימת השליחה, ולכן האכיפה יציבה ובטוחה יותר. עדיין חשוב לעבוד בזהירות, אבל בפועל רמת ההגנה גבוהה יותר.

מדריך התקנה — Outlook

לפני ההתקנה, הורידו את קובץ המניפסט ושמרו במחשב.

Before installing, download the manifest file and save it on your computer.

Outlook Desktop (Windows / Mac)
  1. פתחו את אפליקציית Outlook (לא דפדפן).
  2. בחרו קובץ (File) → קבלת תוספים (Get Add-ins).
  3. בחרו תוספים מותאמים אישית (My Add-ins) → הוספה מותאמת (Add a custom add-in) → הוספה מהקובץ (Add from file).
  4. בחרו את קובץ המניפסט שהורדתם.
  5. אשרו את ההתקנה. אם Outlook מבקש — סגרו ופתחו מחדש את Outlook.
  6. בכתיבת הודעה חדשה, ודאו שהתוסף BCC Alert מופיע (בסרגל או בהגדרות התוספים).
מקום לצילום מסך — התקנה ב-Outlook Desktop
Outlook Web (דפדפן)
  1. היכנסו ל-outlook.office.com.
  2. לחצו על הגדרות (Settings) → הצג את כל הגדרות Outlook.
  3. עברו ל-דואר → תוספים מותאמים (Custom add-ins) (אם זמין בארגון שלכם).
  4. בחרו הוספה מתוך קובץ / Add from file והעלו את קובץ המניפסט.
  5. אם האפשרות לא מופיעה — ייתכן שנדרשת התקנה מרכזית על ידי מנהל IT (Microsoft 365 Admin Center).
  6. לאחר ההתקנה, רעננו את הדפדפן ופתחו הודעה חדשה לבדיקה.
מקום לצילום מסך — התקנה ב-Outlook Web
Outlook Desktop (Windows / Mac)
  1. Open the Outlook desktop app (not the browser).
  2. Select File → Get Add-ins.
  3. Choose My add-ins → Add a custom add-in → Add from file.
  4. Select the manifest file you downloaded.
  5. Confirm installation. If Outlook asks, restart Outlook.
  6. When composing a new message, confirm BCC Alert appears (ribbon or add-in settings).
Screenshot placeholder — Outlook Desktop install
Outlook on the web
  1. Go to outlook.office.com.
  2. Click Settings → View all Outlook settings.
  3. Open Mail → Custom add-ins (if available in your organization).
  4. Choose Add from file and upload the manifest file.
  5. If the option is missing, your IT admin may need central deployment (Microsoft 365 Admin Center).
  6. After install, refresh the browser and open a new message to test.
