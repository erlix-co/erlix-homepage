התחילו ניסיון חינם ל-7 ימים

הגנו על תיבת Outlook מפני חשיפת נמענים גלויים בטעות — לפני שליחה.

התחלת ניסיון חינם

חשוב לדעת: החסימה אינה הרמטית ב-100%. היא שכבת הגנה חכמה שמפחיתה סיכון באופן משמעותי. בגרסת Outlook ההגנה בטוחה וחזקה יותר מאשר בגרסת Gmail, בזכות נקודת אינטגרציה יציבה יותר עם תהליך השליחה.

איך זה עובד

  1. 1

    מתקינים את תוסף Outlook (מדריך התקנה למטה).

  2. 2

    שולחים לנו את כתובת הדואר של Outlook לאישור והפעלה.

  3. 3

    לאחר אישור — ההגנה פעילה אוטומטית בחשבון שלכם.

תוסף Gmail

בתוסף Gmail אנחנו מזהים דפוסים מסוכנים לפני השליחה ומתריעים למשתמש לעצור ולתקן. בגלל מגבלות סביבת הדפדפן והאינטגרציה של Gmail, זו הגנה חשובה אך לא מוחלטת.

תוסף Outlook

בתוסף Outlook ההתרעה מחוברת עמוק יותר לזרימת השליחה, ולכן האכיפה יציבה ובטוחה יותר. עדיין חשוב לעבוד בזהירות, אבל בפועל רמת ההגנה גבוהה יותר.

מדריך התקנה — Outlook

לפני ההתקנה, הורידו את קובץ המניפסט: manifest.xml (שמרו במחשב).

Outlook Desktop (Windows / Mac)
  1. פתחו את אפליקציית Outlook (לא דפדפן).
  2. בחרו קובץ (File) → קבלת תוספים (Get Add-ins).
  3. בחרו תוספים מותאמים אישית (My Add-ins) → הוספה מותאמת (Add a custom add-in) → הוספה מהקובץ (Add from file).
  4. בחרו את קובץ manifest.xml שהורדתם מהקישור למעלה.
  5. אשרו את ההתקנה. אם Outlook מבקש — סגרו ופתחו מחדש את Outlook.
  6. בכתיבת הודעה חדשה, ודאו שהתוסף BCC Alert מופיע (בסרגל או בהגדרות התוספים).
מקום לצילום מסך — התקנה ב-Outlook Desktop
Outlook Web (דפדפן)
  1. היכנסו ל-outlook.office.com.
  2. לחצו על הגדרות (Settings) → הצג את כל הגדרות Outlook.
  3. עברו ל-דואר → תוספים מותאמים (Custom add-ins) (אם זמין בארגון שלכם).
  4. בחרו הוספה מתוך קובץ / Add from file והעלו את manifest.xml.
  5. אם האפשרות לא מופיעה — ייתכן שנדרשת התקנה מרכזית על ידי מנהל IT (Microsoft 365 Admin Center).
  6. לאחר ההתקנה, רעננו את הדפדפן ופתחו הודעה חדשה לבדיקה.
מקום לצילום מסך — התקנה ב-Outlook Web
